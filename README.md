# circuit-experiments-assistant-bot-For-End-work-

面向大学基础电路实验的混合增强智能助教机器人 · 3D 数字原型（Three.js 静态演示）。

## 边界声明（重要）

- 本仓库为**离线数字原型**，未接真实仪器、摄像头、麦克风、语音识别/TTS。
- 所有读数、电阻值、偏差判断均为内置设计示例，不判合格、不做安全联锁。
- 摄像头仅几何外观，不实际识别色环/拓扑；AI 仅内置规则与预设证据，不做真实学习分析。
- 教师保留上电确认权、价值判断、最终评分权；机器人不碰线、不控电源。
- 报告（DOCX）不在本仓库；本仓库仅放可公开的前端演示与说明。

## 角色分工（演示状态机 S0–S6）

S0 理论示例 → S1 测量异常 → S2 AI 拒判转教师 → S3 教师核验 → S4 学生换件 → S5 教师安全确认 → S6 学生反思归档。

## 本地开发

静态工程，无构建步骤（或 `npm run build` 输出到 `docs/` 或 `public/`）。
