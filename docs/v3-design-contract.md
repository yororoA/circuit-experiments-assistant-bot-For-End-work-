# CircuitBridge v3 — 设计契约（公开摘要）

本文件是 V3 数字原型的公开设计契约摘要。详细内部接口由各模块实现各自维护，本文档只记录用户可见的产品目标、边界与验收方向。

## 产品定位

面向大学入门 DC 串联分压实验的数字概念原型。本原型把电路原理图端子、仿真面包板、测量读数与显式因果主张链接起来。

**不做**：摄像头识别、LLM 语义评分、设备供电控制、教学效果实证。

**做**：一个任务驱动的"观察桥"——把学生的注意力引导到真实端子、真实测量点和证据一致性上。它不是平板支架的必需替代品；其增量价值（空间证据与情境化引导）相对平板支架的优劣仍是待研究问题，不是本原型的既定结论。

## 两类任务（不同目标，不同验收）

1. **restore_nominal（恢复标称）**：诊断指定故障并恢复标称电源与元件（E=5V，R1=1000Ω，R2=2000Ω）与正确串联拓扑。只把 U2 调回 2V 不算恢复；电气条件与证据一致性检查与教师对理解的判断是分开的。
2. **ratio_design（比例设计）**：达成 k=U2/E=R2/(R1+R2)=2/3。允许正阻值组合（含 500/1000Ω）。须比较基线与方案的总电流、总功率与元件功率——相同电压比不等于全电路等效；并报告是否满足题目给出的电流/功率限值。

## 证据 vs 理解（硬边界）

- 学生预测错误后仍可继续探索。例如在 5V 理想分压下预测 12V，系统给出物理边界/数值不匹配的具体说明，预测留在历史里，须与修正预测对照；不静默判对，也不锁死成"猜中才能测"。
- 经典同值异因案例：A=(5V,1kΩ,1kΩ) 与 B=(3.75V,1kΩ,2kΩ) 都给出 U_NG=2.5V。PG 给出 5V vs 3.75V，PN 给出 2.5V vs 1.25V，电流给出 2.5mA vs 1.25mA。任何带预先假设比较的区分性测量都有效；重复 NG 是有效证据但不具区分性。不预设"必须先测 NG 再测 PG"。
- 自由文本永不自动判"理解"。引擎只校验结构化的数值/关系证据；教师判断因果解释、概念混淆与迁移。文本长度不产生"掌握"状态。
- 教师不必批准每次参数改动。

## 端子与接线词汇

所有模块共用六个物理端子：`E_pos`、`E_neg`、`R1_a`、`R1_b`、`R2_a`、`R2_b`。默认串联线 `[E_pos,R1_a]`、`[R1_b,R2_a]`、`[R2_b,E_neg]`。原理图别名 P/N/G 由实际接线推导，不是板上任意点的永久名字。端子点击不等于知道其网络；学生显式声明映射，系统暴露不匹配。无效/开路/电源短路拓扑给出明确不可用读数，不冒充通用电路求解器。

## 观察桥几何（概念模型）

- 镜头 home 位置 (0, 235, 0) mm，俯视实验板中心 (0, 8, -10) mm。
- 板实际 173×113mm（名义 180×120 的工作区域），角 x±86.5、z 约 -66.5…46.5；操作侧 z<0，后部立柱/横梁 z≈110，侧显 x≈140，电源 x≈-140。
- 观察桥后立柱与上部横梁真实支撑 home 镜头，无悬浮传感器。
- HFOV 60°、VFOV 45°，在板角高度半 footprint 131.05×94.08mm；板角射线须全部入镜且无遮挡。
- 传感横臂 (B05) 18×18×104mm，自后梁延伸至传感头上方；头舱 (B06) 61×46×48mm。
- 聚焦模式云台可转向端子，但不宣称继续保持全板覆盖；概览与聚焦分别标注。
- 未知/遮挡是用户可控的观察限制模拟，不是 AI 摄像头置信度；被遮挡端子不能产生"已观察到"的位置证据。

## 场景与产品模型

- 产品 GLB 为中性米制居中整机/零件，不含 FOV、实验台、探针或叠加层；真实开孔/开口，不贴图冒充几何。
- 运行时实验环境与中性产品导出组分离。
- 只读诊断暴露端子世界/画布坐标、镜头位姿/轴、FOV、角点、几何 bbox、灯光材质、镜头四元数、显示状态；不暴露引擎内部 mutator 或 ground truth。

## UI 与对比

- 学生工作台：任务目标明确、原理图与仿真板联动、预测/数值反馈、假设比较、证据历史、结构化因果提交、教师响应分栏。
- 不强制每次测量/编辑后切教师。教师面板暴露错误概念证据；应用分类会改变学生可见引导与后续响应路径。
- 配色：暖中性、深石墨、克制 teal，不重紫/靛蓝。桌面与 390px 移动可访问控件；暂停冻结编辑但不冻结 Orbit 观察；提示真实可达。
- "设备 vs 平板视图"切换展示同一任务与证据、无机器人几何；标注为"提议的对比"，不是机器人必要/更优的证明。

## 验收方向（不沿用旧版 22 PASS）

- 错误 12V 预测反馈与修正；
- 500/1000Ω 在恢复任务失败、在比例任务成功（须附正确 I/P 证据）；
- 任意自由文本不自动产生掌握；
- 替代 PG/PN/电流区分与重复 NG 歧义；
- 教师提示真实改变学生引导并记录响应；
- 提示控件可达；
- 映射/接线编辑与场景/SVG 一致；
- 未知观察状态可区分；
- 灯光/镜头/显示状态真实动态；
- FOV 角点/遮挡/间隙；
- GLB 静态与动态下载 loader bbox；
- 桌面 + 移动真实指针/触摸；
- 最终 Pages 当前 SHA。
